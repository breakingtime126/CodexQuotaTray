# 到期前 1 分钟自动使用重置卡

从 **0.2.38** 起，未保存过此开关时**默认开启**。右键托盘 →“设置 → 自动使用重置卡”可关闭；已保存的关闭选择不会因升级而被覆盖。勾选表示当前启用，悬停提示和“帮助与诊断 → 查看连接诊断”说明到期前 **60 秒（1 分钟）**的触发时机及当前状态。

旧版 0.2.37 只在实际切换开关时保存设置，没有保存过的默认关闭状态会采用新版默认开启。已有设置文件损坏、格式不支持或不可读时仍安全关闭，不会当作首次使用。重新开启需阅读确认提示并成功保存。不改变工具的自动更新、数据来源、公共提醒或 TPS 功能。

## 运行方式

- 使用当前所选 Codex 组件已有的登录和官方 app-server 接口，不自行读取、复制或传输登录令牌。
- 对明确返回 ID、可用状态、Codex 额度重置类型和到期秒数的卡，在到期前 60 秒唤醒现有额度查询。只选择最早到期的卡，并再次核对账号、卡 ID 和期限后发出请求。
- 服务端决定当前额度是否可重置。不人为消耗额度，不按剩余额度阈值触发，不购买卡或付费重置。
- 每次查询最多尝试一张卡。同到期时间的不同卡按 ID 稳定排序；已完成的卡不会阻止后续卡，但每张都必须通过独立服务端检查。
- 使用现有短时查询进程和一次性计时器，不增加长期后台进程或高频轮询。正常额度刷新频率保持不变。

## 安全与异常

- 休眠、关机、离线、组件启动/网络延迟、系统时间不准或服务限流可能错过时刻。恢复或重启时，只有仍在最后一分钟内并完成新查询验证的卡才可尝试；到期后不发出新使用请求。无法保证在离线期间使用成功。
- 无 ID、无账号标识、到期时间未知/未返回、永不过期、非可用状态、未知类型或重复冲突 ID 均不自动使用。仅有数量时不让后端任意选卡。
- 请求前把操作 UUID 写入本地文件并落盘，以账号和卡的哈希隔离。跨进程独占锁防止两份程序同时使用同一张卡；记录不可写、损坏或被占用时停止操作。
- 超时或断开不能当成使用失败。先重新查询；同一张卡仍可用且未到期时，最多重试一次，间隔至少 10 秒，并复用原 UUID。重启也读取该记录，不生成新的操作 ID。若该卡消失、变为使用中或已经到期而结果仍未知，会持续暂停该账号的其他自动用卡，不从卡数量推断成功；需在 Codex 中核对，关闭再开启不会清除未确认记录。
- `reset` / `alreadyRedeemed` 表示成功/同操作已完成；`nothingToReset` / `noCredit` 表示当前无需重置/无可用卡，本卡不再自动重试。所有已发出的使用请求之后都重新查询额度，查询失败时不会把旧额度当成新状态。
- 使用请求被服务限流时遵守现有 5 分钟冷却，并保存重试限制；不会为了赶到期绕过限流。
- 组件不支持使用方法时暂停自动使用并显示原因，不切换认证方式。可更新 Codex 组件后关闭再开启此选项；此前已返回“不支持”的同一张卡仍不自动重试，可在 Codex 中手动处理。
- 关闭选项立即阻止尚未发出的请求，但已经发送的请求无法撤回。设置保存失败会明确提示。

开关悬停提示和“帮助与诊断 → 查看连接诊断”显示固定中文结果，不显示账号、卡 ID、操作 UUID、登录令牌或服务端原始错误。
