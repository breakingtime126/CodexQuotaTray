# 0.2.35 验证记录

本版补齐公共重置数据的 GitHub 镜像与客户端读取链路。个人额度、TPS、更新签名信任和自动更新安装流程不变。

## 本地云构建验证

- .NET SDK 8.0.427，完整 Core 测试：1628/1628 通过（Linux）。
- net48 单文件 EXE 构建成功，零警告、零错误。
- PowerShell 7.5.4 离线传输测试：116 项通过；实际 producer → Core 协议、镜像解析、历史重置显示、304、429、隐私错误映射通过。
- Python 镜像任务：11 项通过，包括失败不更新旧文件或成功时间、限流、重复键、边界校验、拒绝重定向以及数据分支非强制更新。
- 新增镜像测试覆盖新鲜、过期、未来时间、原站裸数据拒绝、历史事件有效、304 不续期与 UI 到期隐藏。
- 客户端使用新的 `Fetch-ResetState-0.2.35.ps1` 文件名，保留旧版本脚本；已有同名文件不匹配时仍拒绝运行。资源固定 LF 行尾，避免不同构建平台改变嵌入脚本字节。

## 发布门槛与限制

GitHub Actions 发布流程另外运行 Windows Core 测试、两组 PowerShell 离线测试和 Python 镜像测试，随后生成并签名实际发布 EXE。完整结果以对应版本 Actions 记录为准，本文件不提前声明云端发布成功。

GitHub 数据镜像需在发布客户端前初始化真实数据。计划同步可能延迟，客户端对超过 60 分钟未成功同步的数据隐藏处理。保留 PowerShell 7.5+ 要求，尚无公共重置 PS5.1 通道。

Windows 托盘实机交互和普通用户自动替换生命周期没有在管理员权限的 GitHub 托管构建机上执行，不将离线测试等同实机升级验证。
