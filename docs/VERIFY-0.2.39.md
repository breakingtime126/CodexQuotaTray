# 0.2.39 验证记录

## 变更

- 按用户指定文案，将“设置”中的开关名称固定为“自动使用重置卡”。状态和设置警告不再追加到菜单文字上，避免把菜单撑宽。
- 到期前 60 秒的说明、当前状态及设置错误继续显示在悬停 tips、辅助功能描述和连接诊断中。
- 其余菜单层级、默认开启与保留手动关闭的策略、自动使用安全检查和更新逻辑均不改变。0.2.38 已发布内容保持不变。

- 原生菜单测试使用更新后的短标签；不登录账号、不使用真实重置卡、不调用更新安装。
- 可见托盘键盘交互、混合 DPI/跨屏和休眠恢复仍不属于本次实际运行验收。
