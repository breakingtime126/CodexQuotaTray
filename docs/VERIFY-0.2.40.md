# 0.2.40 验证记录

## 范围

- 基于 0.2.39 / 0eca7c575f8301bcaf948ddb267db015aca84d11。
- 按明确要求移除 Desktop 额度查询额外计算、比较的全文件 SHA-256，不增加缓存。
- 移除生产 DesktopImageHasher、SHA 字段及哈希预算；保留总体 40 秒协作式预算、取消、512 MiB 单镜像限制。
- 保留签名/发布者、Store 注册和 manifest、PE/尺寸、路径、防重解析点、只读租约及启动前重验。
- 新诊断身份追加为 RegisteredPackageVersionAndSignature；旧枚举数值和公开诊断形状保留，生产 hash 字段归零。
- 更新包的下载/签名/哈希验证、TPS 指纹和调度没有改动。
- 正式版 FileVersion/AssemblyVersion 为 0.2.40.0，ProductVersion 为 0.2.40；高于旧版 0.2.39.0 和预览版 0.2.39.1。
- 正式发布沿用现有 Windows CI、签名更新清单和成对资产验证；仅新增固定 release/0.2.40 分支触发，仍要求提交已在 main 历史中。普通 main 推送不会触发发布。
- 正式 Release 将成为 Latest，并提供签名 update.json，供开启自动更新的现有程序下载、验证和安装。未直接操作用户电脑。

## 已知语义变化

不再保证 runtime 和包内程序逐字节相同。匹配尺寸与 PE 版本、且均通过可信 OpenAI 签名检查的文件可被接受。
双方缺少 PE 版本时保持原兼容行为，一方缺失时仍不匹配。不能宣称移除前后的身份约束完全相同。
Windows 签名 API 本身仍可能全文件读取/摘要；不能把额外 SHA-256 的去除当成整个查询无 CPU 开销。

## 回归设计

- 合成虚拟 PE 的主体不可读取；1 KiB、373,698,352 字节、512 MiB 三个长度均只读 16 字节 PE 字段，没有显式哈希。
- 同尺寸/版本的不同合成内容仍经过签名回调，验证已去除字节一致性要求。
- 非 PE、非 x64、DLL、空/超大文件、尺寸不匹配在签名前拒绝。
- 签名失败不进入版本读取；保留注册变化、版本不匹配、路径变更、租约释放、超时和取消测试。
- 原本只测试已删除哈希函数的用例替换为新边界用例；旧诊断协议兼容性测试保留。
